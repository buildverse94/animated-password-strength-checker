# 🔐 Animated Password Strength Checker

A modern, responsive **Password Strength Checker** built using **HTML, CSS, and JavaScript**. This project features a beautiful Glassmorphism UI, real-time password strength analysis, a password generator, and interactive animations.

## ✨ Features

- 🔒 **Real-Time Strength Analysis** — Evaluates password strength as you type.
- 📊 **Live Strength Meter** — Displays the password strength percentage.
- 👁️ **Show/Hide Password** — Toggle password visibility.
- 🎲 **Password Generator** — Generate strong passwords instantly.
- 📋 **Copy Password** — Copy generated passwords with one click.
- ✅ **Password Requirements** — Checks length, uppercase, lowercase, numbers, and special characters.
- 🎨 **Glassmorphism UI** — Modern interface with glowing effects and smooth animations.
- 📱 **Responsive Design** — Designed to work across different screen sizes.

## 🛠️ Technologies Used

- **HTML5** — Page structure
- **CSS3** — Styling, gradients, glass effects, and animations
- **JavaScript** — Password analysis, generation, visibility toggle, and copy functionality

## 🔍 Password Requirements

The checker evaluates whether a password contains:

- At least 8 characters
- An uppercase letter (A–Z)
- A lowercase letter (a–z)
- A number (0–9)
- A special character (such as `@`, `#`, or `!`)
